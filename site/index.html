CodeShelf Light

A desk light that shows what your AI coding agents are doing, so you look at the screen exactly when you need to.

Download GitHub Bluetooth app

One glance

WorkingThe agent is busy.
WaitingIt is done and waits for you.
Needs youA permission or a question.
ErrorSomething failed.

Why

  • Works with your agents: Claude Code, Gemini CLI, GitHub Copilot CLI, Cursor, and any tool that can run a command on an event.
  • Your colors: color, pattern and speed for each state, set from your phone.
  • Answer from your phone: optionally, permission requests and questions show on the light's page, and you can send prompts from its Chat tab.
  • Several lights: one per project, one per agent, or one on every desk.
  • No cloud: the light lives on your WiFi or a USB cable. Nothing leaves your network.
  • Cheap hardware: an ESP32-S3 board with a built-in RGB LED, about €5.

Get started

  1. Get a Waveshare ESP32-S3-Zero and a USB-C data cable. Want to support the development? Buy the board through this affiliate link: I get a small commission, you pay the same, and it helps cover the costs.
  2. Download CodeShelf Light Setup for your system (see above), install the firmware and set up WiFi.
  3. Install the VS Code extension from the same release:
code --install-extension codeshelf-light-1.0.0.vsix

It finds the light, adds it, and offers to add the hooks for Claude Code. Start an agent and watch the light.
