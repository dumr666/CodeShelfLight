# CodeShelf Light firmware

ESP32-S3 firmware for the CodeShelf Light (PlatformIO, Arduino framework).

```bash
pio run -t upload       # build and flash over USB
```

- [Firmware guide](../docs/firmware.md): building, flashing, OTA updates, settings page, Bluetooth app
- [Protocol](../docs/protocol.md): HTTP, USB serial, Bluetooth LE, mDNS
- [Hardware](../docs/hardware.md): boards and LED pins
